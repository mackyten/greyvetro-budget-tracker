## Decisions locked in (do not re-litigate)
- Export scope: CSV/PDF export + JSON import/restore
- Streak location: drawer header
- Month lock: takes effect immediately on toggle (separate save call)
- Vault bank/card records: optional soft-link to Account.id (plain string, no type coupling)

- PIN required before vault access is allowed at all (no "unprotected" fallback)
- Inflation baseline: today's pesos
- Notification scheduling: inexact (no SCHEDULE_EXACT_ALARM)
- Biometric/voice/home-widget: Android-only, no iOS work
